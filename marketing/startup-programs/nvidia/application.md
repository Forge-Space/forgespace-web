### Company name

### What does your company do?
Forge Space builds open-source AI governance infrastructure for software development teams. Our MCP-native platform (Siza) enables AI-assisted code generation with quality scoring and safety controls, routing across multiple LLM providers including NVIDIA NIM.

### What stage is your startup?
Pre-seed. Product in production with 834 users.

### What NVIDIA technology do you use or plan to use?
We use and plan to use:
- **NVIDIA NIM** for inference via our mcp-gateway provider routing layer
- **NVIDIA AI Enterprise** models for code generation workloads
- Planning to add NVIDIA NIM API as a first-class provider in mcp-gateway (alongside OpenAI, Anthropic, Google)

### How does your product use AI?
Core product (Siza) uses AI for:
1. Code generation — users describe what they want, AI generates structured code packages
2. Quality scoring — AI-based code review and governance checks
3. MCP tool orchestration — AI agents interact with developer tools via Model Context Protocol

### Team size
2 (founder + collaborators). Open-source community contributors.

### Funding stage
Pre-seed / bootstrapped.

### What problem are you solving?
Software teams adopting AI code generation lack governance and quality controls. Forge Space adds the safety layer — quality scoring, provider routing, and audit trails — on top of AI code generation, making AI-assisted development safe for enterprise adoption.
